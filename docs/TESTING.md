# الاختبارات

يشغل `scripts/test-all.ps1` اختبارات Backend مع coverage، ثم lint وTypeScript وVitest وNext build.

تتحقق المجموعة من Backend وFrontend دون تثبيت أرقام ثابتة قد تصبح قديمة مع إضافة الاختبارات.

تغطي Pytest: قراءة Excel وCSV، اكتشاف الأوراق/مجموعة البيانات، المعاينة، الاستدلال الدلالي، كشف الغموض، جودة البيانات، حدود الإيجنتات الثلاثة، حسابات DuckDB، الحسابات الطبيعية الآمنة والتحقق المزدوج، DashboardSpec، منع الرقم غير الموثق، interrupt/resume، الحد الأقصى وfallback، وفحص API الكامل.

تغطي اختبارات Ollama بعقود محلية حتمية: فرض JSON Schema، حذف `sample_values` من الـPrompt، رفض الأعمدة المختلقة، وإيقاف LangGraph بأمان عند فشل المزود. الاختبار الحي للنموذج نفسه يتم على جهاز العرض بعد `ollama pull llama3.2`، لأن النموذج لا يُنزّل داخل CI.
