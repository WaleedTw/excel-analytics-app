# نظرة عامة على المشروع

## المشكلة

ملفات Excel وCSV شائعة في المؤسسات العربية، لكن استخراج مؤشرات موثوقة منها يتطلب فهم البنية، تنظيف القيم، اختيار الحساب المناسب، ثم بناء عرض قابل للتفسير. الأدوات العامة قد تخفي جودة البيانات أو تسمح لنموذج لغوي باختلاق رقم.

## الحل

«بيّنة» تنفذ رحلة مضبوطة: Data Loader آمن، ثم إيجنت تنظيف، وإيجنت تحليل وحسابات، وإيجنت داشبورد، مع تدخل بشري للغموض، حسابات DuckDB/Pandas، تحقق Pydantic، ثم عرض DashboardSpec ثابت في Next.js.

## النطاق الحالي

تدعم النسخة XLSX وCSV، مجموعة بيانات واحدة لكل تشغيل، حسابات مخصصة باللغة الطبيعية، 1–5 محاولات، وذاكرة checkpoint قصيرة الأجل. PostgreSQL وCelery/Redis موثقان في Docker Compose بينما يعمل التشغيل المحلي بـSQLite ومهام خلفية داخل العملية.
