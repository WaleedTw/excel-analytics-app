# نظرة عامة على المشروع

## المشكلة

ملفات Excel شائعة في المؤسسات العربية، لكن استخراج مؤشرات موثوقة منها يتطلب فهم البنية، تنظيف القيم، اختيار الحساب المناسب، ثم بناء عرض قابل للتفسير. الأدوات العامة قد تخفي جودة البيانات أو تسمح لنموذج لغوي باختلاق رقم.

## الحل

«بيّنة» تنفذ رحلة مضبوطة: فحص أمني، اكتشاف الأوراق، معاينة، استدلال دلالي، تدخل بشري للغموض، تقرير جودة، حسابات DuckDB، تحقق Pydantic، ثم عرض DashboardSpec ثابت في Next.js. يُحفظ التحليل في SQLite وJSON محليين.

## النطاق الحالي

تدعم النسخة XLSX، ورقة واحدة لكل تشغيل، وضع LLM محليًا دون مفتاح، 1–5 محاولات، وذاكرة checkpoint قصيرة الأجل. PostgreSQL وCelery/Redis موثقان في Docker Compose بينما يعمل التشغيل المحلي بـSQLite وInline Jobs.
