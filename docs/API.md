# Bayyinah API v2

الأساس المحلي: `http://127.0.0.1:8001/api/v1`، والتوثيق التفاعلي عند `/docs`.

| الطريقة | المسار | الغرض |
|---|---|---|
| GET | `/health` | حالة الخدمة ومزود LLM |
| POST | `/files` | رفع XLSX أو CSV آمنًا |
| POST | `/samples/{sales\|messy}` | تحميل ملف Excel تجريبي |
| GET | `/files/{id}` | بيانات الملف ومجموعات البيانات |
| GET | `/files/{id}/preview?sheet=` | معاينة الصفوف وملفات الأعمدة |
| POST | `/analyses` | بدء تحليل خلفي |
| POST | `/analyses/{id}/resume` | استئناف تحليل ينتظر توضيحًا |
| GET | `/analyses/{id}` | حالة التحليل ونتيجته وسجل الإيجنتات |
| POST | `/analyses/{id}/ask` | سؤال طبيعي عن البيانات المتحققة |
| POST | `/analyses/{id}/calculations` | إنشاء حساب مخصص طبيعي وآمن |

## حساب مخصص

الطلب:

```json
{
  "instruction": "هامش الربح = الربح ÷ الإيرادات × 100"
}
```

الاستجابة تتضمن: اسم الحساب، الصيغة، القيمة، التنسيق، أعمدة المصدر، عبارة التحقق، والاستعلام المقيد الذي جمع الأعمدة.

## سجل الإيجنتات

تضيف استجابة التحليل حقل `agent_runs`. لكل عنصر:

- `agent`: المعرف البرمجي.
- `label`: الاسم المعروض.
- `responsibility`: نطاق المسؤولية.
- `status`: حالة التنفيذ.
- `summary`: ملخص هذه الجولة.
- `artifacts`: المخرجات القابلة للتدقيق.

## أخطاء متوقعة

- `404`: ملف أو تحليل غير موجود.
- `409`: حالة الجلسة لا تسمح بالعملية.
- `422`: ملف غير صالح، سؤال غير قابل للفهم، أو صيغة حساب غير آمنة.

المرجع: [FastAPI response models](https://fastapi.tiangolo.com/tutorial/response-model/).
