# الحواجز والخصوصية

- امتدادا XLSX وCSV فقط؛ رفض الأسماء والمسارات غير الآمنة والحجم/الأبعاد الكبيرة والملفات التالفة والفارغة.
- توقيع XLSX وفواصل CSV وترميزاته مقيدة، وتُرفض ملفات CSV الثنائية أو المشوهة.
- أسماء تخزين UUID وعدم استخدام اسم المستخدم كمسار.
- `data_only=True` و`keep_links=False` وعدم تنفيذ ماكرو أو كود.
- رصد النصوص التي تبدأ بـ`= + - @` كخطر Formula Injection وعدم تنفيذها.
- الحسابات في Python/DuckDB فقط، باستعلامات يبنيها التطبيق من أسماء أعمدة مقتبسة.
- الحسابات المخصصة تستخدم AST مقيدًا دون `eval` أو دوال أو استدعاءات، وتُطابق بين DuckDB وPandas.
- عدم تنفيذ كود يولده النموذج وعدم إرسال الملف كاملًا إليه.
- `DashboardSpec` وZod حاجزان خلفي وأمامي.
- `assert_numeric_provenance` يرفض أي رقم في الرؤى لا يطابق نتيجة محفوظة.
- حد محاولات 1–5 وfallback صريح وسجل قرار عربي.

النسخة المحلية لا تتضمن مصادقة أو تعدد مستأجرين. للإنتاج يلزم تشفير مخزن الملفات، مصادقة، سياسة احتفاظ، PostgreSQL، checkpointer دائم، فحص برمجيات خبيثة، وتحديد معدلات.
