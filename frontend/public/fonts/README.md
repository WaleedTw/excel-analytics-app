# خط ثمانية

تتضمن هذه النسخة الملفات الرسمية المرخصة من عائلتي `Thmanyah Sans` و`Thmanyah Serif Display` بصيغة WOFF2، بالأوزان Light وRegular وMedium وBold وBlack.

- يستخدم `Thmanyah Sans` للنصوص وعناصر الواجهة.
- يستخدم `Thmanyah Serif Display` للعناوين، ويُعرّف داخل CSS باسم `Thmanyah Display`.
- توجد نسخة الترخيص المرفقة مع حزمة الخط في `LICENSE.pdf`.

تُحمّل الخطوط محليًا من `app/globals.css` ولا تحتاج إلى اتصال بالإنترنت.
